# 1. OVERALL GOAL

Expand the existing WeGrowKids.org website by creating a professional **Projects portfolio** that introduces the major educational and community initiatives being developed or operated through We Grow Kids.

The Projects section should communicate that We Grow Kids is more than a tutoring service. It is an education and youth-development organization building multiple learning environments for children, families, student-athletes, homeschoolers, and community partners.

The four initiatives to feature are:

1. **Creekside Warriors Student Athlete Academy**
2. **Afrofuturism Discovery Academy**
3. **Virtual Villages**
4. **Friday Farm**

Each initiative should have its own dedicated project page.

The website should feel:

* Professional
* Welcoming
* Youth-centered
* Family-centered
* Innovative
* Community-rooted
* Future-focused
* Educational
* Culturally responsive
* Easy to navigate on mobile

Do not make the individual programs feel like disconnected businesses.

They should visually and structurally feel like members of the larger **We Grow Kids ecosystem**.

---

# 2. IMPORTANT DEVELOPMENT RULES

Before making changes:

1. Review the current site structure.
2. Identify reusable components already being used.
3. Preserve all existing working functionality.
4. Do not remove existing pages unless explicitly instructed.
5. Do not delete the existing **Friday Garden Lab** page.
6. Preserve all current booking, tutoring, payment, login, contact, calendar, admin, and lead-generation functionality.
7. Reuse the site's existing design language where appropriate.
8. Build reusable components rather than duplicating large amounts of code.
9. Ensure every page works properly on:

   * Desktop
   * Tablet
   * Mobile
10. All new forms should connect to the existing admin/lead infrastructure whenever technically possible.

If exact information is unavailable, use clearly labeled temporary placeholders in the code/content rather than inventing details.

Example:

`[PROGRAM SCHEDULE TO BE CONFIRMED]`

Do not present an unknown detail to website visitors as fact.
