Build a full professional website for We Grow Kids, a homeschool education support business that serves families with private tutoring, curriculum resources, gardening enrichment classes, and parent support.

The website should feel warm, trustworthy, culturally responsive, family-centered, and professional. The audience is homeschooling parents, charter school families, and parents looking for personalized academic support.

Create the following pages:

1. Home
2. About
3. Private Tutoring
4. Curriculum Resources
5. Friday Gardening Class
6. Homeschool Support
7. Store
8. Parent Portal / Login
9. Testimonials
10. Contact / Book a Call
11. Policies

Homepage:
Create a strong hero section with the headline:
“Helping Homeschool Families Grow Confident Learners”

Subheadline:
“We Grow Kids provides tutoring, curriculum resources, gardening enrichment, and parent support designed to help children grow academically, creatively, and confidently.”

Add three main buttons:
“Book Tutoring”
“Join Friday Gardening Class”
“Browse Curriculum Resources”

Add a section called “What We Offer” with cards for:

* Private Tutoring
* Curriculum Resources
* Friday Gardening Class
* Homeschool Support
* Small Group Learning

Private Tutoring Page:
Include sections for:

* 1-on-1 tutoring
* Small group tutoring
* Math support
* Literacy support
* Homework help
* Homeschool learning plans
* Parent progress updates

Add pricing placeholders:

* 1-on-1 Tutoring: $50/hour
* Small Group Tutoring: discounted rate
* Learning Consultation: pricing placeholder

Add a registration form collecting:
Parent name, student name, grade, subject support needed, learning goals, IEP/504 information if applicable, preferred days/times, email, phone number, and consent to receive email/text updates.

Curriculum Resources Page:
Create a store-style page with placeholder products:

* Math Mini Lessons

* Parent Teaching Guides

Each resource should have:

* Image placeholder

* Grade level

Create a contact form with:
Name, email, phone, student grade, service interested in, message, and preferred contact method.
